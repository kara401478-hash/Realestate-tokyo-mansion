# 東京23区 中古マンション取引データ分析(約12万件)

国土交通省の不動産取引価格情報(2018年第1四半期〜2026年第2四半期)から、東京23区の中古マンション取引 **118,856件** を前処理・分析し、「同じ区の中でも駅によって価格がどれだけ違うか」をモデルで定量化したプロジェクトです。

## 結論

- **区の平均で価格を見積もると、駅によって大きくずれる。** 同じ条件(面積・築年数・駅距離など)で予測した価格と実際の価格の差は、駅によって大きく、件数30件以上の駅で最大 -25.6%〜+43.6% ありました。査定や仕入れの目安は、区単位ではなく駅単位で補正するのが望ましいです。
- 区の中央値だけで予測した場合の誤差率(中央値)は22.6%。物件条件を加えたモデルでは **13.1%** に下がりました(直近4四半期を未来として検証)。
- 23区全体の㎡単価の中央値は、2018年第1四半期の83.3万円から2026年第2四半期の118.0万円へ、約42%上昇しました(中央値の単純比較で、物件構成の変化を含みます)。

## 主な結果

| 項目 | 内容 |
|---|---|
| 区別の㎡単価(中央値) | 最高は港区140.0万円、最低は足立区52.9万円(約2.6倍) |
| 築年数 | 築5年以内の123.1万円から段階的に下がり、築21〜30年の90.0万円から築31〜40年で65.7万円へ一段下がる。築41年以上は65.0万円でほぼ横ばい |
| 駅距離 | 10分以内は108.0万→100.0万円と緩やか。11〜15分で80.0万円、16分以上で55.7万円と大きく下がる |
| 価格を左右する要因 | 築年数、区、取引時期、面積の順に影響が大きい |

予測より高く取引されている駅(件数50件以上の例): 目黒(+32.0%)、代官山(+28.5%)、日暮里(+26.3%)、新宿(+24.9%)
予測より安く取引されている駅(同): 小村井(-20.2%)、西新宿五丁目(-18.7%)、落合南長崎(-18.6%)

駅ごとの全結果は、`03_model.py` を実行すると `data/output/station_gap.csv` に出力されます

## 進め方

### 1. 前処理(`01_clean.py`)
| 段階 | 件数 |
|---|---|
| 読み込み(東京都・中古マンション等・取引価格情報) | 140,888 |
| 東京23区に絞り込み | 121,256 |
| 価格・面積・築年・取引時点の欠損を除外 | 119,223(2,033件除外) |
| 異常値を除外(築年マイナス、面積10〜500㎡外、㎡単価の上下0.1%) | 118,856(367件除外) |

建築年は和暦・西暦・「戦前」が混在するため数値に統一し、取引時点(「2023年第1四半期」)や駅距離(「30分?60分」)も数値化しています。除外した件数は段階ごとに記録しています。

### 2. 探索的分析(`02_analyze.py`)
区別、四半期推移、築年数帯別、駅距離帯別の㎡単価(中央値)を集計し、グラフ化します。

### 3. 価格予測と駅ごとの乖離(`03_model.py`)
- **モデル**: 勾配ブースティング(scikit-learnのHistGradientBoostingRegressor)。目的変数は㎡単価の対数。損失は絶対誤差で、極端な駅に区全体の予測が引きずられるのを防いでいます。
- **説明変数**: 面積、築年数、駅距離、取引時期、区、構造、改装。駅名・地区名は入れていません(入れると駅ごとの差が予測に吸収されるため)。
- **検証**: 2018年〜2025年第2四半期で学習し、直近4四半期(11,512件)を予測。誤差率の中央値13.1%、R² 0.729。
- **駅ごとの乖離率**: 各取引の予測は5分割の交差検証で出し(その取引を学習に使わない)、直近3年・1駅30件以上の駅(399駅)について、予測との差の中央値と、ブートストラップによる95%区間を計算しています。
- 「関係者間取引」「調停・競売等」など特殊な事情が付いた取引(630件)は除外しています。

## 注意点

- 階数、向き、管理状態などはデータにありません。**乖離率が大きい駅は「調べる価値のある候補」であり、割安・割高と断定するものではありません。**
- 399駅のうち約55%が±5%以上の候補になりました。駅の立地(路線・ターミナル性・ブランド)による差が残差に含まれていると考えられます。
- 面積は5㎡刻みに丸められた値で、㎡単価に誤差が含まれます。
- 駅数が多いため、偶然に差が出て見える駅も含まれます。件数の少ない駅(30〜40件台)は区間が広く不安定です。
- 区は取引物件の所在地で、駅は最寄駅です。そのため、駅が実際には隣の区にある場合も、物件の区の下に表示されます。
- 取引件数は約12万件で、一般にいうビッグデータ(数千万行〜)ではなく、中規模のデータです。

## 再現手順

```
pip install -r requirements.txt
```

1. [不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp)の「データの検索・ダウンロード」で、東京都・中古マンション等・不動産取引価格情報(2018年第1四半期〜)のCSVをダウンロードします。
2. 実行します。

```
python 01_clean.py "ダウンロードしたCSVのパス"
python 02_analyze.py
python 03_model.py                           # 既定: 直近3年・1駅30件以上・乖離5%以上を候補
python 03_model.py --min-n 50 --min-gap 15   # 厳しめの条件
```

結果は `data/output/` に出力されます。
